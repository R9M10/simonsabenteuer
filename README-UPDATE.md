# Milchbuck-Update – mit Sprung und Schuss

Diese ZIP enthält die aktualisierte `game.js`.

## Neu

Nach dem Dialog startet Simon an der pixelartigen Tramhaltestelle **Milchbuck**. Beim Laufen nach rechts scrollt die Kamera in eine Zürich-inspirierte Stadtkulisse.

Die bisherige Steuerung bleibt erhalten:

- **← / →** beziehungsweise **A / D**: laufen
- **J** beziehungsweise **W / Leertaste / Pfeil hoch**: springen
- **X**: Schussanimation

Auf dem iPhone im Querformat bleiben deshalb weiterhin vier Touchbuttons sichtbar: **←**, **→**, **J** und **X**.

Die bestehenden Dateien `index.html`, `script.js`, `style.css`, `simon-spritesheet.png` und die bisherigen Assets bleiben unverändert.
